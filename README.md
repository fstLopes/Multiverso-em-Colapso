# Multiverso em Colapso
Multiverso em Colapso é um jogo do gênero Tower Defense, desenvolvido utilizando a engine GameMaker. O jogo apresenta uma mistura de diferentes universos, personagens originais e situações de humor e sátira. O jogador deve posicionar unidades defensivas pelo mapa para impedir que os inimigos percorram a rota e alcancem seu objetivo.

O projeto faz parte do Farmando XP 2026, do IFTM – Campus Patrocínio, e tem como um de seus principais focos o balanceamento das mecânicas do jogo, buscando criar uma progressão de dificuldade adequada por meio do ajuste das unidades, inimigos e ondas.

Como baixar e jogar

Multiverso em Colapso é um Tower Defense para Windows. Não precisa instalar nada: é só baixar, descompactar e abrir.

1. Baixar
Acesse o repositório: https://github.com/fstLopes/Multiverso-em-Colapso
Clique no botão verde Code, acima da lista de arquivos.
Escolha Download ZIP.
O arquivo Multiverso-em-Colapso-main.zip vai para a sua pasta de Downloads.
Não baixe só o arquivo .exe

Clicando direto nele, o GitHub baixa apenas aquele arquivo — e o jogo não abre. Ele precisa do data.win, que é onde estão os mapas, os sprites e os sons. Baixe o ZIP inteiro.

2. Descompactar
Clique com o botão direito no ZIP baixado.
Escolha Extrair tudo e confirme.
Abra a pasta extraída e entre em MC v0.32.

Você deve ver três arquivos:

Arquivo	O que é
Multiverso em Colapso.exe	O jogo
data.win	Todo o conteúdo: mapas, sprites e sons
options.ini	Configurações internas

Os três precisam ficar juntos na mesma pasta. Mover só o .exe para a área de trabalho não funciona.

Se quiser um atalho, clique com o botão direito no .exe e escolha Enviar para → Área de trabalho (criar atalho). O atalho pode ficar em qualquer lugar; os arquivos, não.

3. Abrir o jogo

Dê dois cliques em Multiverso em Colapso.exe.

Se aparecer um aviso azul do Windows, é normal — ele aparece para qualquer programa sem certificado de empresa, o que inclui praticamente todo jogo independente. Clique em Mais informações e depois em Executar assim mesmo.

Se o antivírus reclamar, também acontece. Jogos feitos em GameMaker são marcados por engano com frequência, porque compartilham a mesma estrutura de arquivo. Baixando pelo link oficial acima, pode liberar.

4. Começando a jogar
No menu, clique em JOGAR e digite seu nome (mínimo de 3 letras).
Escolha a dimensão e o modo:
História — vença as 20 ondas. A nota vai de 1 a 3 estrelas, conforme as vidas que sobrarem.
Infinito — as ondas não acabam. Destrava ao concluir a História daquela dimensão.
Clique em JOGAR de novo para confirmar.
Durante a partida
Clique em CONSTRUIR, à direita, para abrir a loja de heróis.
Clique num espaço livre ao lado do caminho para posicionar.
Clique numa torre já posicionada para ver alcance, status e melhorias. Atalhos: T melhora, V vende.
A primeira onda só começa quando você clicar em INICIAR. Use esse tempo para montar a defesa.
P pausa.
