# Multiverso em Colapso
Multiverso em Colapso é um jogo do gênero Tower Defense, desenvolvido utilizando a engine GameMaker. O jogo apresenta uma mistura de diferentes universos, personagens originais e situações de humor e sátira. O jogador deve posicionar unidades defensivas pelo mapa para impedir que os inimigos percorram a rota e alcancem seu objetivo.

O projeto faz parte do Farmando XP 2026, do IFTM – Campus Patrocínio, e tem como um de seus principais focos o balanceamento das mecânicas do jogo, buscando criar uma progressão de dificuldade adequada por meio do ajuste das unidades, inimigos e ondas.
